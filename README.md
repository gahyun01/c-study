## 📌 기준 표준

##### 📖 정의
1999년에 제정된 C 언어의 국제 표준인 **ISO/IEC 9899:1999** ( 이하 **C99** )를 기준으로, 범용적으로 사용할 수 있는 코드를 정리한다.

##### ✨ 특징
- 특정 컴파일러에 종속되지 않는 표준 문법을 다룬다.
- 표준에 따라 구현된 컴파일러라면 종류에 상관없이 학습과 실습에 큰 문제가 없다.
